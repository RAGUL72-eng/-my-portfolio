# Ragul V. — Personal Portfolio

A minimal, premium, responsive React + Tailwind CSS portfolio generated from the information available in the supplied resume.

## Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The original resume PDF is included in `public/Ragul resume.pdf` and is wired to the **Download Resume** button.

## Notes

- No project GitHub/live-demo URLs were present in the resume, so the project cards intentionally show placeholders.
- No portrait/photo was found in the resume, so the design uses a visual placeholder treatment rather than inventing a photo.
- No specific physical location was provided in the resume; the header's `Hybrid` text is retained because it appears in the resume contact line.
- The contact form is intentionally dummy functionality and displays `Message sent`.
